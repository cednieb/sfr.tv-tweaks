
<br/>C'est un userscript à charger avec une extension dans un navigateur WEB.
<br/>Gerer certaines erreurs, personalisation de l'interface utilisateur.
<br/>

# Navigation au clavier

<br/>"+" ou la flèche droite pour la chaine suivante
<br/>"-" ou la flèche gauche pour la précédente
<br/>Avec les chiffres ( pavé numérique ou pas ) comme une télécommande
<br/>La touche entrée numérique ou la touche contrôle gauche affiche ou ferme une mosaïque de vignettes (cliquer pour changer la chaine)
<br/>Passer en mode plein écran ou fenêtré avec le point du pavé numérique ou la touche majuscule gauche
<br/>
<br/>Gestion du volume sonore avec les flèches , haut pour augmenter , bas pour diminuer
<br/>Interface de configuration du tableau de vignettes , appuyer sur "V"
<br/>Interface de configuration , appuyer sur C
<br/>Logs erreurs , appuyer sur L
<br/>
<br/>

# Navigation à la souris

<br/>Mettre la souris sur le bord gauche de l'écran fait apparaître le menu
<br/>Ajout de boutons pour fermer les menus
<br/>Ajout d'un slider pour la gestion du son
